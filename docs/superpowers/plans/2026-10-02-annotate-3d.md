# Annotate in 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Annotate gets a 2D/3D toggle that shows the annotated document on the 3D model: marks in their colours, lamp colours and states, seated optics, and a legend panel.

**Architecture:** Three PRs.
1. A kit fix in Portrayal: the GLB/USDZ export leaves the mark halos out.
2. A site refactor: Explorer's 3D wiring moves into `site/mode3d.js`, with no behaviour change.
3. A site feature: Annotate uses `mode3d.js`, plus a pure `docToScene()` in `site/annotate3d.js` that turns the marks document into viewer calls.

**Tech Stack:** Plain ES modules with no bundler. `vendor/viewer3d.js` (three.js 0.161, through the page's import map). Playwright through `check-browser.py`. `node --test` for pure modules.

**Spec:** `docs/superpowers/specs/2026-10-02-annotate-3d-design.md` (portrayal-site). Issue: portrayal-site#46.

## Global Constraints

- **Purpose: on screen.** 3D exports are the plain model, without mark plates. 2D exports keep the marks.
- **Labels in 3D** are an HTML legend panel beside the stage, never drawn in the scene.
- **The marks document schema (`marks.js` v1) does not change.** The mode travels as `?mode=3d` in the URL, beside the `#…` document.
- **The 3D button is disabled below portrayal level 3** (`CAN_3D = 3`), with the build's reason as its title: `3D needs <needs>` or `3D needs portrayal level 3`.
- **Colours reaching the viewer** must pass `marks.js`'s hex rule: `/^#(?:[0-9a-f]{3}|[0-9a-f]{4}|[0-9a-f]{6}|[0-9a-f]{8})$/i`. State names must pass `/^[a-z0-9-]+$/`.
- **A mark's `state` replaces** the element's existing `state-*` classes, as `marks.apply` does in 2D.
- **Explorer behaves exactly as today.** Its existing browser checks pass unchanged.
- **Every site PR is gated by:**
  - `python3 check-contract.py` and the full `python3 check-browser.py`;
  - a push through the real hook, `git -c core.sshCommand="ssh -o ServerAliveInterval=30" push`, with no `--no-verify`;
  - code review, then a handoff to the "Portrayal-site merge agent" session. Never merge or push `main`.
- **Every Portrayal PR is gated by:**
  - `cd kit && npm test`;
  - the relevant `spec/tests`;
  - code review, then a handoff to the "PR review and merge queue" session.
- **Work in worktrees,** never in `/Volumes/External/portrayal-site` itself. Kill only PIDs you started.
- **Comments** follow the house style: a capitalised lead phrase, then why. Name no person and no private tooling.

## Review Focus

1. **A selector that is invalid CSS** (for example `[data-path=` typed half-way) must not throw out of `docToScene`. The mark gets `error` set and no paths, and every other mark still reaches the scene. Pinned in Task 6.
2. **A mark whose selector matches on a face other than the 2D view** (a rear-only fan while the front is shown) must still be marked in 3D. Pinned in Task 6 (faces) and Task 10 (`fan-2` in the browser).
3. **Switching to 3D before `loadFaces()` has resolved** must not drop marks on faces still loading. `setMode` re-runs `sync()` once the faces arrive (Task 2). Pinned in Task 10: `fan-2` is on the rear face, which is only held after `loadFaces()`.
4. **A click in 3D on the part that is already selected** must toggle its mark exactly as a second 2D click does, with no double toggle from Explorer's own "click again clears". Pinned in Task 10.
5. **Leaving 3D** must re-enable the 2D-only export buttons and give them back their original titles. Pinned in Task 10.

### Task 2: `site/mode3d.js`

**Files:**

**Interfaces:**
- Consumes these shell members: `state`, `el.fit`, `el.stage`, `el.status`, `el.svgHost`, `el.view`, `on`, `emit`, `select`, `stage()`, `device()`, `loadFaces`, `refreshTree`, `fit`, `pulledPaths`.
- Produces `createMode3d(shell, opts)`, which returns:

| member | what it is |
|---|---|
| `mode()` | `'2d'` or `'3d'` |
| `setMode(m)` | a Promise |
| `sync()` | a Promise; re-sends the page's state and reloads when the load key changed |

| `on('mode', fn)` | mode-change listener |
| `el` | `{modeBar, host3d, fruBox}` |

`opts` carries:

| option | default | what it does |
|---|---|---|
| `states` | `() => ({})` | the `{path: 'state-…'}` map to send |
| `pulled` | `() => shell.pulledPaths()` | the pulled paths to send |
| `overrides` | `() => ({})` | the swap overrides for `load()` |
| `afterSync` | none | `async (v) => {}`, run on every sync after states and pulls |
| `extras` | none | `(v, host3d) => {}`, run once when the viewer first exists |

- [ ] **Step 1: Write the module.** This is Explorer's code moved verbatim, with its comments, behind the hooks above.

```js
// THE 2D/3D SWITCH, SHARED. The 3D scene is a module mounted into a container
// beside the SVG stage - same page, same tree, same inspector, no iframe and no
// message protocol. It was Explorer's alone; Annotate needs every piece of it,
// and the ordering fixes below were each paid for once and should not be paid
// for twice. A page hands in what is ITS state - which lamps are lit, what is
// pulled, what is swapped - and mounts its own chrome through `extras`.
//
// The viewer is imported on first use: it drags in three.js and a WebGL
// context, and someone who never presses 3D should pay for neither.

export const MODE3D_CSS = `
  #mode { display:flex; gap:0.2rem; }
  #mode button { border-radius:0; }
  #mode button:first-child { border-radius:6px 0 0 6px; }
  #mode button:last-child { border-radius:0 6px 6px 0; margin-left:-1px; }
  #mode button:disabled { opacity:0.45; cursor:not-allowed; }
  #mode button:disabled:hover { background:var(--pt-surface-2); }
  /* NOT position: relative HERE. .stage-host is position:absolute; inset:0, and
     overriding that collapses the stage to nothing. */
  #stage-3d { background:var(--pt-surface); }
  #stage-3d canvas { display:block; }
  #frus { display:flex; gap:0.2rem; flex-wrap:wrap; }
  #frus[hidden] { display:none; }        /* display:flex outranks the hidden attribute */
  #frus button { font-family:ui-monospace, monospace; font-size:0.72rem; padding:0.26rem 0.42rem; }
  #glx { position:absolute; bottom:0.6rem; left:0.7rem; z-index:5; display:flex;
         gap:0.3rem; align-items:center; font-size:0.72rem; }
  #glx button:disabled { opacity:0.55; cursor:progress; }
  #glx .msg { color:var(--dim); }
  #glx .msg.bad { color:var(--warn); }
`;

// A scene needs six faces that describe one box, which is exactly portrayal
// level 3. Below it the viewer has nothing to extrude the sides from and draws a
// plausible wrong box instead.
const CAN_3D = 3;
const kb = n => n < 1048576 ? `${Math.round(n / 1024)} KB` : `${(n / 1048576).toFixed(1)} MB`;

export function createMode3d(shell, opts = {}) {
  const state = shell.state;
  const {
    states = () => ({}),
    pulled = () => (typeof shell.pulledPaths === 'function' ? shell.pulledPaths() : []),
    overrides = () => ({}),
    afterSync = null,
    extras = null,
    onPick = p => shell.select(p && p !== state.sel ? p : null, false),
  } = opts;
  const listeners = {mode: []};

  const modeBar = document.createElement('span');
  modeBar.id = 'mode';
  modeBar.innerHTML = `<button data-mode="2d" class="on">2D</button><button data-mode="3d">3D</button>`;
  shell.el.fit.before(modeBar);

  const host3d = document.createElement('div');
  host3d.className = 'stage-host';
  host3d.id = 'stage-3d';
  host3d.hidden = true;
  shell.el.stage.appendChild(host3d);

  const fruBox = document.createElement('span');
  fruBox.id = 'frus';
  fruBox.hidden = true;
  shell.el.status.before(fruBox);

  let mode = '2d', viewer = null, loading = null, loadedKey = '';

  async function ensureViewer() {
    if (viewer) return viewer;
    if (!loading) loading = (async () => {
      const {createViewer} = await import('../vendor/viewer3d.js');
      // THE BACKGROUND IS THE READER'S. The shell owns the swatches and the 2D
      // stage; the scene is told the colour it starts with and every change after.
      const v = createViewer(host3d, {dist: 'assets/dist/', background: shell.stage()});
      shell.on('stage', c => v.setBackground(c));
      // WHAT IS WRITTEN ON A PART reaches the scene as well as the drawing.
      shell.on('fields', ({all}) => v.setFields(all));
      if (Object.keys(state.cfgFields || {}).length) v.setFields(state.cfgFields);
      // A HANDLE FOR MEASURING, not for using: `?debug=1` puts the viewer on
      // window so a console or a browser check can ask it what it holds.
      if (new URLSearchParams(location.search).get('debug') === '1') window.__viewer = v;
      // A click on nothing emits null, and a drag to orbit is filtered before it
      // gets here. What a pick MEANS is the page's: Explorer toggles the
      // selection, Annotate toggles a mark.
      v.on('select', p => onPick(p));
      mountDownloads(v);
      if (extras) extras(v, host3d);
      return v;
    })();
    try {
      viewer = await loading;
    } catch (err) {
      loading = null;               // a rejected promise would poison every retry
      throw err;
    }
    return viewer;
  }

  // A GLB is the one output that survives someone not being able to reach the
  // site. The module does the exporting; the page is two buttons and a line.
  function mountDownloads(v) {
    if (typeof v.download !== 'function') return;
    const bar = document.createElement('div');
    bar.id = 'glx';
    bar.innerHTML =
      `<button data-fmt="glb" title="Geometry and textures in one file. Opens in Quick Look, Windows 3D Viewer, PowerPoint, Blender, Sketchfab.">Download GLB</button>`
    + `<button data-fmt="usdz" title="AR Quick Look on iPhone and iPad.">USDZ</button>`
    + `<span class="msg"></span>`;
    host3d.appendChild(bar);
    const msg = bar.querySelector('.msg');
    const all = [...bar.querySelectorAll('button')];
    for (const b of all) b.onclick = async () => {
      const fmt = b.dataset.fmt;
      all.forEach(x => { x.disabled = true; });
      msg.classList.remove('bad');
      msg.textContent = `building ${fmt.toUpperCase()}…`;
      try {
        const {name, size} = await v.download(fmt);
        msg.textContent = `${name} — ${kb(size)}`;
      } catch (err) {
        msg.textContent = `${fmt.toUpperCase()} failed: ${err.message || err}`;
        msg.classList.add('bad');
      } finally {
        all.forEach(x => { x.disabled = false; });
      }
    };
  }

  // One button per removable unit, carrying the unit's own path - the name the
  // tree row and the halo already use. toggleFru returns the next state.
  function fruBar(v) {
    fruBox.replaceChildren();
    if (typeof v.frus !== 'function' || typeof v.toggleFru !== 'function') return;
    for (const fru of v.frus() || []) {
      const btn = document.createElement('button');
      btn.dataset.fru = fru.path;
      const paint = st => {
        btn.textContent = `${st.icon} ${st.path}`;
        btn.classList.toggle('on', !!st.out);
        btn.title = `${st.label} — ${st.out ? 'insert' : 'eject'}`
                  + ` (${Math.round(st.travel)} mm travel${st.captive ? ', captive' : ''})`;
      };
      paint(fru);
      btn.onclick = () => {
        const st = v.toggleFru(fru.path);
        if (!st) return;
        paint(st);
        shell.el.status.textContent = st.text || '';
      };
      fruBox.appendChild(btn);
    }
  }

  // THE SWAP STATE IS PART OF WHAT IS ON SCREEN, so it is part of the key. A
  // runtime swap changes no file on disk, so the overrides have to travel with
  // the load AND be visible to the early return.
  const swapKey = () => Object.entries(overrides())
    .sort(([a], [b]) => a < b ? -1 : 1)
    .map(([k, v]) => `${k}=${v || ''}`).join(',');

  async function sync() {
    if (mode !== '3d') return;
    const v = await ensureViewer();
    const key = `${state.device}.${state.cfg}|${swapKey()}`;
    // BEFORE the early return, and before the load: states and pulls set while
    // the drawing was showing are exactly the case where the device and the
    // swaps have not changed and the scene still has to catch up; and build()
    // reads them, so a scene comes up already lit.
    await v.setStates(states());
    await v.setPulled(pulled());
    // The page's own state (Annotate's marks and lamp colours), at the same
    // point and for the same reason. The viewer keeps marks across a rebuild.
    if (afterSync) await afterSync(v);
    if (key === loadedKey) return;
    await v.load({device: state.device, config: state.cfg, overrides: overrides()});
    loadedKey = key;                // only once it is actually the thing on screen
    fruBar(v);
    if (state.sel) v.select(state.sel);
  }

  function pushStates() {
    if (mode !== '3d' || !viewer) return;
    Promise.resolve(viewer.setStates(states()))
      .catch(err => console.warn('[portrayal] 3D state sync failed', err));
  }
  function pushPulled() {
    if (mode !== '3d' || !viewer) return;
    Promise.resolve(viewer.setPulled(pulled()))
      .catch(err => console.warn('[portrayal] 3D pull sync failed', err));
  }
  shell.on('pulled', pushPulled);

  async function setMode(m) {
    if (m === mode) return;
    mode = m;
    for (const b of modeBar.querySelectorAll('button')) b.classList.toggle('on', b.dataset.mode === m);
    shell.el.svgHost.hidden = m !== '2d';
    host3d.hidden = m !== '3d';
    // the FRU bar is 3D chrome; Fit measures the SVG stage, which is 0x0 while hidden
    fruBox.hidden = m !== '3d';
    shell.el.fit.hidden = m === '3d';
    shell.emit('mode', m);
    for (const fn of listeners.mode) fn(m);
    // IN 3D THE VIEW IS NOT A CHOICE: the scene shows all six faces, so the tree
    // merges and the view picker steps aside. Only if the shell can.
    const viewPick = shell.el.view.closest('label') || shell.el.view;
    const canMerge = typeof shell.loadFaces === 'function';
    const merge = m === '3d' && canMerge;
    state.merge = merge;
    viewPick.style.display = merge ? 'none' : '';
    // Faces arriving after the switch can carry marks the first sync could not
    // see, so the scene is synced again once they are all held.
    if (merge) shell.loadFaces().then(() => { shell.refreshTree(); return sync(); })
      .catch(err => console.warn('[portrayal] faces for the merged tree', err));
    else shell.refreshTree();
    if (m === '2d') {
      shell.fit();
      if (state.sel) shell.select(state.sel, true);
      return;
    }
    shell.el.status.textContent = 'loading 3D…';
    try {
      await sync();
      (await ensureViewer()).resize();
      shell.el.status.textContent = '';
    } catch (err) {
      console.warn('[portrayal] 3D unavailable', err);
      shell.el.status.textContent = `3D unavailable: ${err.message || err}`;
      setMode('2d');
    }
  }
  for (const b of modeBar.querySelectorAll('button')) b.onclick = () => setMode(b.dataset.mode);

  // Absent capability data leaves the button as it was: a device the build has
  // not judged is not a device we refuse to draw.
  const btn3d = modeBar.querySelector('[data-mode="3d"]');
  shell.on('device', (name, meta) => {
    const cap = meta?.capability || shell.device()?.capability;
    const short = cap && cap.level != null && cap.level < CAN_3D;
    btn3d.disabled = !!short;
    if (!short) { btn3d.title = ''; return; }
    const needs = (cap.blocked || []).find(b => b.level === CAN_3D)?.needs;
    btn3d.title = needs ? `3D needs ${needs}` : `3D needs portrayal level ${CAN_3D}`;
    if (mode === '3d') setMode('2d');
  });

  shell.on('select', path => { if (mode === '3d' && viewer) viewer.select(path); });
  const failed = what => err => {
    console.warn(`[portrayal] 3D ${what} failed`, err);
    shell.el.status.textContent = `3D unavailable: ${err.message || err}`;
  };
  shell.on('change', () => { sync().catch(failed('swap sync')); });
  shell.on('load', () => { sync().catch(failed('reload')); });
  addEventListener('resize', () => { if (mode === '3d' && viewer) viewer.resize(); });

  return {
    mode: () => mode, setMode, sync, pushStates,
    viewer: () => viewer,
    on: (ev, fn) => { (listeners[ev] ||= []).push(fn); },
    el: {modeBar, host3d, fruBox},
  };
}
```

```js
// WHAT AN ANNOTATION SAYS, IN THE SCENE'S TERMS. Annotate's document marks
// parts with CSS selectors against a drawing; the 3D viewer takes paths. This
// resolves every mark against EVERY face the shell holds - a mark on the rear
// PSUs is a mark in 3D even while the front is the drawing on the other tab -
// and returns what the viewer's setMarks, setLampColors and setStates take.
// Pure: faces in, plain objects out, no viewer and no page.

import { match } from '../vendor/marks.js';

// The same rules as marks.js: a colour reaches a CSS value slot, so hex only;
// a state is a class name, so a token.
const HEX_RE = /^#(?:[0-9a-f]{3}|[0-9a-f]{4}|[0-9a-f]{6}|[0-9a-f]{8})$/i;
const STATE_RE = /^[a-z0-9-]+$/;
const hex = v => (typeof v === 'string' && HEX_RE.test(v) ? v.toLowerCase() : '');

// A selector that matches a group and its children marks the part once.
function outermost(els) {
  const set = new Set(els);
  return els.filter(e => {
    for (let p = e.parentNode; p && p.nodeType === 1; p = p.parentNode) if (set.has(p)) return false;
    return true;
  });
}

/**
 * @param doc    a marks document ({marks: [{select, color, lamp, state, label}]})
 * @param faces  {view: svgRoot}, every face the shell holds
 * @returns {{marks: {path, color}[], lamps: Object, states: Object,
 *            byMark: {paths: string[], error: string|null}[]}}
 */
export function docToScene(doc, faces) {
  const colour = new Map(), lamps = {}, states = {}, byMark = [];
  for (const m of (doc && doc.marks) || []) {
    const paths = new Set();
    let error = null;
    for (const root of Object.values(faces || {})) {
      if (!root) continue;
      let r;
      try { r = match(root, m); } catch (e) { r = {els: [], error: String(e.message || e)}; }
      if (r.error) { error = r.error; continue; }
      for (const el of outermost(r.els)) if (el.dataset && el.dataset.path) paths.add(el.dataset.path);
    }
    // LATER MARKS WIN, as later rings paint over earlier ones in 2D.
    const c = hex(m.color), l = hex(m.lamp);
    const st = typeof m.state === 'string' && STATE_RE.test(m.state) ? `state-${m.state}` : '';
    for (const p of paths) {
      if (c) { colour.delete(p); colour.set(p, c); }
      if (l) lamps[p] = l;
      // A STATE REPLACES, as marks.apply removes an element's state-* classes
      // before adding the mark's.
      if (st) states[p] = st;
    }
    byMark.push({paths: [...paths], error});
  }
  return {marks: [...colour].map(([path, color]) => ({path, color})), lamps, states, byMark};
}

/**
 * The legend panel's rows: as marks.js's strip, one per labelled mark that
 * reached something - here on any face - in document order. The swatch is the
 * ring colour, else the lamp colour; hollow when there is no ring.
 */
export function legendItems(doc, scene) {
  return ((doc && doc.marks) || []).flatMap((m, i) => {
    if (!m.label || !scene.byMark[i] || !scene.byMark[i].paths.length) return [];
    const c = hex(m.color), l = hex(m.lamp);
    return [{label: m.label, color: c || l || '#8d939a', hollow: !c}];
  });
}
```

```python
    page.on("pageerror", lambda e: bad.append(f"uncaught: {e}"))
    doc = {"v": 1, "device": "s9510-28dc", "config": "dc", "view": "front", "legend": True,
           "marks": [
               {"select": "[data-path='port-0']", "color": "#e0574f", "label": "uplink"},
               {"select": "[data-path='port-4']", "color": "#2bb3c8"},
               # fan-2 is drawn on the REAR face only (fans 1-5 exhaust at the back):
               # marked while the front is the drawing, it must still reach 3D
               {"select": "[data-path='fan-2']", "color": "#9b5de5", "label": "exhaust fan"},
               {"select": "#led-gnss", "lamp": "#ff00ff"},
               {"select": "[data-path='led-sync']", "state": "synced"},
               {"select": "[data-class='silkscreen']", "color": "#ffd400"},
           ]}
    page.goto(f"{base}/annotate.html?debug=1", wait_until="load")
    page.wait_for_selector("#stage svg", timeout=READY_MS)
    page.evaluate("""async d => { const m = await import('/vendor/marks.js');
                       location.hash = m.encode(d); }""", doc)
    page.reload(wait_until="load")
    page.wait_for_selector("#stage svg [data-path='port-0']", state="attached", timeout=READY_MS)
    if webgl_trouble(page):
        print("[check_annotate_3d] no WebGL here - checking the fallback only")
        page.click('#mode [data-mode="3d"]')
        page.wait_for_function("() => /3D unavailable/.test(document.querySelector('#status')?.textContent || '')"
                               " || !document.querySelector('#stage-3d').hidden", timeout=READY_MS)
        return bad
    page.click('#mode [data-mode="3d"]')
    page.wait_for_function("() => window.__viewer && window.__viewer.marks().length >= 3", timeout=READY_3D_MS)
    r = page.evaluate("""() => { const v = window.__viewer;
      return {marks: v.marks().map(m => [m.path, m.color]).sort(),
              lamps: v.lampColors(), states: v.states(),
              legend: [...document.querySelectorAll('#legend3d .row')].map(e => e.textContent.trim()),
              notIn3d: [...document.querySelectorAll('#rows .mark')].map(r =>
                /not in 3D/.test(r.querySelector('.notes').textContent)),
              off: [...document.querySelectorAll('.btns button[data-act]')]
                     .filter(b => b.dataset.act !== 'share').every(b => b.disabled && /2D only/.test(b.title))}; }""")
    got = dict((p, c) for p, c in r["marks"])
    for path, colour in [("port-0", "#e0574f"), ("port-4", "#2bb3c8"), ("fan-2", "#9b5de5")]:
        if got.get(path) != colour:
            bad.append(f"annotate 3D: mark on {path} is {got.get(path)}, expected {colour}")
    if "#ff00ff" not in [c.lower() for c in r["lamps"].values()]:
        bad.append(f"annotate 3D: the lamp colour never reached the viewer - {r['lamps']}")
    if r["states"].get("led-sync") != "state-synced":
        bad.append(f"annotate 3D: led-sync state is {r['states'].get('led-sync')}")
    if r["legend"] != ["uplink", "exhaust fan"]:
        bad.append(f"annotate 3D: legend rows {r['legend']}, expected ['uplink', 'exhaust fan']")
    if r["notIn3d"] != [False, False, False, False, False, True]:
        bad.append(f"annotate 3D: 'not in 3D' flags {r['notIn3d']}")
    if not r["off"]:
        bad.append("annotate 3D: a 2D-only export is enabled, or lacks its '2D only' title")

    # A CLICK IN 3D IS A CLICK (Review Focus 4). select() frames the camera on
    # the part, centred, so a real click at the canvas centre lands on it - the
    # whole path: canvas, the viewer's select event, onPick, Annotate's toggle.
    # The first click adds a mark for port-8; a second click on the same part
    # takes it off, exactly once.
    n = len(doc["marks"])
    page.evaluate("() => { window.__viewer.select('port-8'); }")
    page.wait_for_timeout(500)
    box = page.locator("#stage-3d canvas").bounding_box()
    cx, cy = box["x"] + box["width"] / 2, box["y"] + box["height"] / 2
    page.mouse.click(cx, cy)
    page.wait_for_function(f"() => document.querySelectorAll('#rows .mark').length === {n + 1}", timeout=READY_MS)
    page.mouse.click(cx, cy)
    page.wait_for_function(f"() => document.querySelectorAll('#rows .mark').length === {n}", timeout=READY_MS)

    # AN OPTIC SEATED IN 3D KEEPS EVERY MARK. Through the inspector, as a
    # reader does it: select the cage in the tree, choose the first optic.
    page.click(".node[data-path='port-4']")
    page.wait_for_selector("#optic", timeout=READY_MS)
    optic = page.evaluate("() => [...document.querySelectorAll('#optic option')].map(o => o.value).find(Boolean)")
    page.select_option("#optic", optic)
    page.wait_for_function("() => window.__viewer.marks().length >= 3", timeout=READY_3D_MS)
    page.wait_for_timeout(1500)
    after_swap = page.evaluate("() => window.__viewer.marks().map(m => m.path).sort()")
    if not set(got) <= set(after_swap):
        bad.append(f"annotate 3D: seating {optic} in port-4 lost marks {sorted(set(got) - set(after_swap))}")

    # A 3D -> 2D -> 3D round trip leaves the document and the marks as they were
    page.click('#mode [data-mode="2d"]')
    page.click('#mode [data-mode="3d"]')
    page.wait_for_function("() => window.__viewer.marks().length >= 3", timeout=READY_3D_MS)
    after = page.evaluate("() => window.__viewer.marks().map(m => m.path).sort()")
    if after != after_swap:
        bad.append(f"annotate 3D: a 2D/3D round trip changed the marks {after_swap} -> {after}")

    # Back in 2D the exports come back with their own titles (Review Focus 5)
    page.click('#mode [data-mode="2d"]')
    back = page.evaluate("""() => [...document.querySelectorAll('.btns button[data-act]')]
      .every(b => !b.disabled && !/2D only/.test(b.title))""")
    if not back:
        bad.append("annotate: back in 2D, an export is still disabled or still titled '2D only'")

    # A share link made in 3D opens in 3D, with its marks
    page.click('#mode [data-mode="3d"]')
    page.wait_for_function("() => window.__viewer.marks().length >= 3", timeout=READY_3D_MS)
    page.click('.btns button[data-act="share"]')
    url = page.input_value('#share')
    if "?mode=3d#" not in url:
        bad.append(f"annotate 3D: the share link does not record the mode - {url[:80]}")
    page.goto(url.replace("?mode=3d", "?mode=3d&debug=1"), wait_until="load")
    page.wait_for_function("() => window.__viewer && window.__viewer.marks().length >= 3", timeout=READY_3D_MS)

    # The GLB is the model: as many meshes with the marks as without (needs PR 1 synced)
    meshes = page.evaluate("""async () => { const v = window.__viewer;
      const count = async () => { const b = await v.exportData('glb'), d = new DataView(b);
        return (JSON.parse(new TextDecoder().decode(new Uint8Array(b, 20, d.getUint32(12, true)))).meshes || []).length; };
      const held = v.marks(); const marked = await count();
      v.setMarks([]); const plain = await count(); v.setMarks(held);
      return [marked, plain]; }""")
    if meshes[0] != meshes[1]:
        bad.append(f"annotate 3D: the GLB carries the marks ({meshes[0]} meshes marked, {meshes[1]} plain)")
    return bad
```

If the centre click lands on a neighbour (the framing puts the part's centre at the canvas centre, so it should not), the first wait times out. In that case read `window.__viewer.selection` after the click to see what was hit.
